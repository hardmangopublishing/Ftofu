## How to host on GitHub Pages

1. Create a new repository on GitHub (e.g. `ftofu` or `ftofu-site`)
2. Upload all files from this folder (or push via Git)
3. Go to **Settings → Pages**
4. Source: Deploy from branch → `main` → `/ (root)`
5. Save. Your site will be live at `https://yourusername.github.io/repo-name/`
6. Later add custom domain `ftofu.com` in the same Pages settings
